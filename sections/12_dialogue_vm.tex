\section{A Dialogue on Memory Virtualization}

\begin{frame}{Memory Virtualization: Summary}
    \begin{itemize}
        \item Every address generated by a user program is a
              \textbf{virtual address}.
        \item The OS, with hardware support, translates virtual addresses
              into \textbf{physical addresses}.
        \item Each process sees the illusion of a \textbf{large, private,
              and contiguous address space}.
        \item Virtual memory provides \textbf{ease of use, isolation,
              and protection} between processes.
        \item Key mechanisms include \textbf{base/bounds, TLBs,
              and multi-level page tables}.
    \end{itemize}
\end{frame}
