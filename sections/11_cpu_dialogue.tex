\section{Summary Dialogue on CPU Virtualization}

\begin{frame}{CPU Virtualization: Summary}
    \begin{itemize}
        \item CPU virtualization relies on mechanisms such as
              \textbf{traps, timer interrupts, and context switching}.
        \item The OS balances \textbf{efficient execution} with maintaining
              \textbf{control over the machine}.
        \item Scheduling policies such as \textbf{SJF, RR, and MLFQ}
              address different performance goals.
        \item Scheduler design involves \textbf{trade-offs}, particularly
              between turnaround time and response time.
        \item OS design is ultimately about combining appropriate
              \textbf{mechanisms and policies} pragmatically.
    \end{itemize}
\end{frame}
